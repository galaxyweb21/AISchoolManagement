How Book Categories Work

Book categories help organize your library collection by subject or genre (e.g., Science Fiction, Mathematics, History). Each category can have multiple books assigned to it. The Books column shows how many books belong to each category. Use the search box below to filter categories by name or description. Click "Add Category" to create a new category for your library.
