How Fee Adjustments Work

This page allows you to add manual adjustments to a student's fee. Adjustments can be Extra Charges (e.g., additional fees), Discounts, Refunds, or Corrections. Each adjustment is tracked with a description and can be managed independently. Click "Add Adjustment" to create a new adjustment for this student.
