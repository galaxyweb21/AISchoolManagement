How Fee Structures Work

Fee structures define the price list for each school class per term. Each structure contains multiple Fee Items from different Fee Categories. The Total shows the sum of all items. Use the search box below to filter structures by class name or term. Click "Add Structure" to create a new fee structure, or "Edit" to modify an existing one. Only Published structures can be used for fee preparation.
